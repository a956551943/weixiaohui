## 七、购物详解（店名 · 楼层 · 预约）

### 7.1 iPhone + 日本电话卡：划不划算？

| 项目 | 结论 |
|------|------|
| Apple 直营店 | **对游客已不做消费税免税**，游客买机通常不划算 |
| **友都八喜（ヨドバシ）/ 爱电王（ビック）** | 游客可 **免税 10%**；近年标价常比 Apple 官网高约 10%，**免税后大致打平官网税前价**，额外看当日库存与积分活动 |
| Apple 产品 | Bic 的「再减 7%」访日优惠券 **通常不含 iPhone**，别指望叠优惠 |
| 推荐店 | **D4 去 ヨドバシカメラ マルチメディア梅田**（大阪站北口，大深町 1-1）；备选日可先去 **ビックカメラ なんば** 比价 |
| 带什么 | 护照原件、信用卡；当场办免税手续 |
| 回国用 | 买 **SIM フリー** 机；回国可装国内卡 / 国内 eSIM |

**电话卡（要「回国也保留」请看清）**

| 需求 | 方案 | 哪里办 | 说明 |
|------|------|--------|------|
| 仅旅行期间上网 | 旅游 **数据 eSIM**（Airalo / Holafly / IIJmio Japan Travel 等） | 出发前网上；或机场 / **罗森 Lawson** 买 IIJmio 卡 | **到期失效**，不能当长期日本号码 |
| 要日本手机号且回国后还能留 | 需 **带语音的长期方案**（如面向海外住民的 HanaCell 等） | 一般 **不能**靠友都八喜随便办一张就「永久保留」 | SoftBank / Y!mobile 店内合约多要日本住所证明；游客难办长期号 |
| 实操建议 | 旅程用数据 eSIM；若必须保留日号，出发前在国内研究好海外住民套餐，**不要指望店里 10 分钟搞定** | 友都八喜 1F 有 SoftBank / Y!mobile 柜台可咨询 | 咨询时说明「访日 / 要回国后仍保留」 |
